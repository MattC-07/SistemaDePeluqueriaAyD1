# 💈 Sistema de Gestión para Barbería

Proyecto desarrollado para el curso de **Análisis y Diseño de Sistemas** - Universidad de Antioquia (UdeA).

---

## 📌 Descripción
Aplicación web moderna para la administración integral de una barbería. Permite gestionar turnos, servicios, clientes, barberos y llevar el control operativo del negocio de manera eficiente e intuitiva.

---

## 🚀 Tecnologías Utilizadas

- **Frontend / Entorno:** [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Gestor de Paquetes:** [pnpm](https://pnpm.io/)
- **Diseño & Prototipado:** Figma
- **Control de Versiones:** Git & GitHub

---

## 🛠️ Instalación y Configuración Local

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

### 1. Clonar el repositorio
\`\`\`bash
git clone https://github.com/MattC-07/sistema-de-barberia.git
cd sistema-de-barberia
\`\`\`

### 2. Instalar dependencias
\`\`\`bash
pnpm install
\`\`\`

### 3. Iniciar el servidor de desarrollo
\`\`\`bash
pnpm dev
\`\`\`

La aplicación estará disponible en `http://localhost:5173/` (o el puerto que asigne Vite).
